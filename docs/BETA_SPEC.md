# LIVARA Beta – Scope

## Ziel
Beweisen, dass Besucher relevante lokale Profile finden und Anbieter für zusätzliche Sichtbarkeit zahlen würden.

## Enthalten
- 18+-Gate
- Stadt-/Kategorie-Suche
- Filter „Heute verfügbar“ und „Verifiziert“
- Sponsored Listings klar gekennzeichnet
- Profilseite
- Anbieter-Dashboard
- Quick-Boost-Demo mit Credit-Wallet
- Abo-Modelle Free / Pro / Premium
- Admin-/Moderationsansicht
- Supabase/Postgres-Schema mit RLS-Grundlage
- Responsive Mobile-Layout

## Bewusst nicht enthalten
- Zahlungsanbieter
- echtes Identity-KYC
- echter Messenger
- echte Bildmoderation
- öffentliche Bewertungen
- komplexe Buchung/Payments
- KI-Matching
- Forum/Social Feed

## Beta-KPIs
1. Suchergebnis -> Profilrate
2. Profil -> Anfrage-Rate
3. Anbieteraktivierung (Profil vollständig)
4. Boost-Kaufabsicht
5. Wiederkehrende Anbieter

## Produktions-Gates
- Rechtsprüfung / AGB / Datenschutz / Jugendschutz
- Zahlungsanbieter, der das Geschäftsmodell ausdrücklich unterstützt
- Moderations- und Abuse-Prozesse
- Supabase-Projekt + Storage + Auth
- Domain/Markenprüfung; LIVARA ist nur Arbeitsname
